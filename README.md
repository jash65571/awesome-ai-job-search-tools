## How to choose the right tool

Pick based on your biggest current problem.

| Problem | Tool type to use |
|---|---|
| Resume isn't getting responses | ATS resume checker |
| Tailoring takes too long | Resume tailoring tool |
| You lose track of applications | Job tracker |
| You need referrals | Email finder / referral tool |
| You're applying to tech jobs | Job matching + ATS tools |
| You're worried about fake jobs | Job scam checker |
| You want speed | Chrome extension / autofill |
| You want interview practice | Mock interview tool |
| You want salary leverage | Salary database |

## What to avoid

Be careful with tools that:

- Promise guaranteed interviews or guaranteed jobs
- Apply to jobs without showing you what they submit
- Hide what answers they fill in for screening questions
- Ask for sensitive data without a clear privacy policy
- Use fake reviews or fabricated success stories
- Make it hard to cancel a paid plan
- Mass-spam recruiters or employees
